# Дизайн-токены исходного сайта

## Шрифт

Единственный шрифт на всём сайте — **Anonymous Pro** (моноширинный, Google Fonts):

```
https://fonts.googleapis.com/css2?family=Anonymous+Pro:wght@400;700
```

Фолбэк: `Arial, sans-serif`.

⚠️ Подключены только начертания **400 и 700**, но в стилях используется `font-weight: 100`
для всех крупных заголовков. Реального тонкого начертания нет — браузер отдаёт 400.
При переделке либо взять шрифт с настоящими светлыми весами, либо честно писать 400.

## Сетка и раскладка

- Контейнер Zero-блоков: **1200 px**
- Брейкпоинты: **1200 / 1199 / 959 / 639 / 479**
- Герой: `height: 100vh`, `min-height: 800px` (на ≤479px — `500px`)
- Отступы секций: `padding 45–60px` сверху/снизу, на мобильном `15–30px`
- Кнопки: transition `0.2s ease-in-out` на `background-color, color, border-color, box-shadow, opacity, transform, gap`
