## Что за сайт

Одностраничный лендинг студии флористики и сет-дизайна **ELEMENT by МОСК** (Москва).
Собран на Tilda: комбинация Zero-блоков (T396) для смысловых секций и готовых
блоков для галерей (T1148), карусели кейсов (T1196), магазина (T776 + корзина T706).

Навигация — якорная, одна страница, 6 пунктов меню.

## Наблюдения к переделке

**Сильное**
- Цельный визуальный язык: моноширинный `Anonymous Pro` на всём сайте, тёмный фон `#161616`, светлый серый текст — узнаваемо и не «как у всех Tilda-шаблонов».
- Контент качественный: сильные тексты, много живых фото (105 файлов), готовые кейсы с описаниями.

**Слабое / что чинить при переделке**
- **Мешанина светлых и тёмных секций** — фон страницы `#333`, услуги `#161616`, кейсы белые, а Zero-блоки прозрачные. Цветовая система не выдержана.
- **Всё держится на Zero-блоках с абсолютным позиционированием** — вёрстка привязана к пикселям на 4 брейкпоинта (1200/960/640/480). Любая правка текста ломает раскладку. Это главная причина переезжать с Tilda.
- **Кейсы живут в попапах** (T1093) — контент не индексируется, нет отдельных URL, нельзя дать ссылку на конкретный кейс. Просятся отдельные страницы.
- **Магазин на 6 позиций с одной ценой** (28 000 ₽ у всех) — по сути каталог, а не магазин; корзина/оформление заказа — избыточная механика.
- **Нет мета-описания** (`description` пустой), title — дефолтный тильдовский.
- Часть фото дублируется между секциями (одни и те же файлы залиты повторно с разными id).
- Дисклеймер про Instagram/Meta обязателен к переносу — юридическое требование для РФ.

## Как воспроизвести снятие

Страница доступна только под логином владельца. Медиа на `static.tildacdn.com` отдаётся
публично, поэтому `assets.txt` качается без авторизации:

```bash
while read -r u; do curl -sLO "$u"; done < assets.txt
```
